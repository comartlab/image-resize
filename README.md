[Image Resize](https://github.com/comartlab/image-resize/releases/latest) is a native macOS app for Apple silicon and Intel that processes single images, batches, or folders into a chosen output folder. It supports resizing with optional upscaling, cropping, adjustable text or PNG watermarks with corner placement, format conversion, web optimization, and output-size estimates. Settings are remembered and originals stay untouched.

Open **Preview & Crop** and choose **Apply to This Image** or **Apply to Batch**. Queue thumbnails outline the area each crop will keep. A batch crop replaces earlier individual crops. You can then adjust or reset the crop for any image in the queue. For crop-only exports, choose **Keep original dimensions**.
