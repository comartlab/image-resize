[Image Resize](https://github.com/comartlab/image-resize/releases/latest) is a native macOS app for Apple silicon and Intel that processes single images, batches, or folders into a chosen output folder. It supports downsizing or keeping original dimensions, batch cropping, adjustable text watermarks, format conversion, web optimization, and output-size estimates. Settings are remembered, originals stay untouched, and images are never enlarged.
